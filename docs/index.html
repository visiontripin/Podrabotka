Архитектура

Один код — два режима

Full-stack с API и SQLite для разработки; автономная сборка в один HTML — для GitHub Pages и телефона.

Браузер

React 18 · TypeScript (strict) · Tailwind CSS · lucide-react

│ src/lib/api.ts — единая точка доступа к данным │

Server · Node 22

Express + node:sqlite, Vite-middleware в dev, dist/ в prod

Offline-движок

src/lib/browserDb.ts — те же эндпоинты, данные в localStorage

Модель данных

users ──┬── jobs ──┬── applications ── messages
        │          └── favorites
        ├── reviews        (взаимные оценки, модерация)
        ├── notifications
        └── tariffs        (лимиты по роли)

regions ── locations      (ISO-коды, валюта, таймзона, локаль)

Быстрый старт

git clone https://github.com/visiontripin/Podrabotka.git
cd Podrabotka
npm install
npm run dev   # http://localhost:3000
  • SQLite через встроенный node:sqlite — без нативных зависимостей
  • tsc --noEmit в strict-режиме проверяет фронтенд и сервер
  • Шрифты Manrope и Unbounded (OFL) лежат локально

Что это такое и чего здесь нет

Работающий MVP с демо-данными, а не продакшен-маркетплейс.

  • Демо-аутентификация. Пользователь приходит заголовком, сессий и паролей нет.
  • Платежи не подключены. «СБП сразу», «На руки», «СМЗ» — модель данных и UI, без реальных выплат.
  • SQLite на один инстанс. Для горизонтального масштабирования нужен PostgreSQL.
  • Данные вымышлены. Вакансии и отзывы сгенерированы, реальные компании не упоминаются.
