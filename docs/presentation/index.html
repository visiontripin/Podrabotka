01 · Проблема

Смена нужна сегодня, а не «в следующем месяце»

Классические job-борды рассчитаны на найм на месяцы. Сменному персоналу и малому бизнесу нужно закрыть смену за часы.

Работодателю

Нужен человек на 4–12 часов: склад, зал, доставка, мероприятие. Вакансия на HeadHunter висит неделю, смена — сегодня вечером.

Исполнителю

Нужен заработок завтра, а не карьера на пять лет. Резюме, собеседования и месячный онбординг — барьер, а не помощь.

Рынку

Агентства берут 15–30% с фонда оплаты и не работают со сменами на один день. Разрыв закрывают чаты и сарафан.

Итог

Между «нужен человек через 4 часа» и «ищу подработку на завтра» нет прозрачного и быстрого инструмента.

Гипотеза MVP: если путь «нашёл → откликнулся → вышел → получил деньги» занимает минуты, а не дни, смены закрываются в тот же день.

02 · Решение

Смена закрывается в тот же день

Три роли в одном приложении: витрина смен, кабинет исполнителя и работодателя, модерация и тарифы.

Публикация за минуту

Название, адрес, дата, часы, оплата. Часовая ставка считается автоматически.

Поиск рядом с домом

Фильтры по метро и МЦД, району, датам, оплате и способу выплаты.

Отклик в один клик

Сопроводительная записка, лимиты по тарифу, воронка кандидатов у работодателя.

Выплата после смены

Закрытие смены фиксирует выплату, заработок и рейтинг обеих сторон.

Ключевой принцип: 0% комиссии с заработка исполнителя. Монетизация — тарифы работодателя и PRO-подписка рабочего.

06 · Доверие

Рейтинг, который нельзя купить

Доверие — главный дефицит на рынке сменного персонала. Поэтому модерация встроена в продукт, а не прикручена сбоку.

Взаимные оценки

Рабочий и работодатель оценивают друг друга после смены. Отзыв виден только после проверки.

Очередь модерации

Каждый отзыв проходит одобрение. Рейтинг пересчитывается мгновенно, отклонённые оценки не влияют.

Индекс выходов

Show-up rate: доля смен, на которые исполнитель действительно вышел. Виден работодателю до принятия.

Верификация

Статус «Проверенный» для компаний и исполнителей. Медкнижка и самозанятость — в профиле.

В демо-версии рейтинг работодателя уже 4,9 при 27 свободных местах — это живые данные сидов, а не картинка.

09 · Архитектура

Один код — два режима

Full-stack с API и SQLite для разработки; автономная сборка в один HTML — для GitHub Pages и телефона.

Фронтенд

React 18, TypeScript strict, Tailwind CSS, lucide-react. Шрифты Manrope и Unbounded лежат локально — ноль внешних ассетов.

Бэкенд

Node 22, Express, встроенный node:sqlite без нативных зависимостей. 10 таблиц, сиды, WAL-режим, 22 эндпоинта.

Офлайн

browserDb повторяет те же эндпоинты на localStorage. Демо живёт на статическом хостинге и с телефона без интернета.

Проверки

tsc --noEmit, сборка, статическая сборка, smoke-тест /api/health в GitHub Actions.

Один контракт данных: src/lib/api.ts — единственная точка доступа, поэтому UI не знает, откуда пришли данные.

11 · Дорожная карта

Что дальше

MVP отвечает на вопрос «работает ли модель». Дальше — инфраструктура продакшена и выход в новые города.

Ближайшие шаги

  • SMS-аутентификация и сессии вместо демо-заголовка
  • PostgreSQL и миграции, вынос API в отдельный сервис
  • Выплаты через СБП и интеграция с самозанятостью
  • Push-уведомления и realtime-чат
  • Админ-аналитика: конверсия, стоимость смены, отток

Что уже работает

  • Три роли и полный цикл смены: публикация → отклик → закрытие
  • Тарифы с лимитами и апгрейдом
  • Модерация отзывов и пересчёт рейтингов
  • Офлайн-сборка и мобильный интерфейс
  • CI: типы, сборка, smoke-тест API
Ограничения MVP: демо-аутентификация, платежи не подключены, SQLite на один инстанс, все данные вымышлены.
