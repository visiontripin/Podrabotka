# Подработка.МСК — полнофункциональный Telegram-бот

Пакет `bot/podrabotka/` — полноценный многофункциональный бот для платформы
**Подработка.МСК**. Бот работает с той же SQLite-базой, что и веб-версия
(`server/index.ts`), через стандартную библиотеку `sqlite3`, поэтому все данные
(отклики, статусы смен, чаты, отзывы, уведомления) синхронизированы в обе
стороны без промежуточного API.

Запуск бота производится через ваше приложение
**[Bot-Control](https://github.com/visiontripin/Bot-Control)** (файл
`*-ready.py`) или напрямую:

```bash
# Полнофункциональный бот (требует data/podrabotka.sqlite)
PODRABOTKA_BOT_TOKEN=123456:ABC-DEF... python bot/podrabotka_bot.py

# Имитационный бот — только демо-данные, без базы данных
PODRABOTKA_BOT_TOKEN=123456:ABC-DEF... python bot/imitation_bot.py
```

## Структура

```
bot/
  podrabotka_bot.py          # тонкая точка входа (import podrabotka.bot:main)
  podrabotka/
    __init__.py              # версия пакета 1.0.0
    config.py                # переменные окружения (PODRABOTKA_*)
    constants.py             # категории, статусы, emoji, BOT_COMMANDS (меню Telegram)
    db.py                    # 데이터-слой поверх той же SQLite (bot_telegram_links, bot_meta)
    format.py                # HTML-форматтеры (job_card, application_line, profile_text, …)
    keyboards.py             # reply-меню по ролям + inline-клавиатуры
    states.py                # in-memory FSM-хранилище + константы состояний
    handlers_common.py       # общие страницы, привязка/регистрация, диспетчеры текста и callback
    handlers_worker.py       # исполнитель: каталог, фильтры, отклик, избранное
    handlers_employer.py     # работодатель: мои смены, создание, кандидаты, принятие/отказ/закрытие
    handlers_admin.py        # модератор: обзор платформы, очередь отзывов
    bot.py                   # класс PodrabotkaBot: TeleBot + фоновый нотификатор + команды
| `imitation_bot.py`         # имитационный бот без базы данных (демо-режим)
| `imitation_bot.txt`         # тот же бот в .txt — для импорта в Bot-Control
```

### Режимы работы

**Полнофункциональный режим** (`bot/podrabotka_bot.py`) — реальный бот с общей SQLite-базой веб-версии. Требует `data/podrabotka.sqlite` (создаётся `npm run dev`).

**Имитационный режим** (`bot/imitation_bot.py`) — бот работает только в режиме демонстрации. Все смены, отклики, пользователи и статусы — фейковые данные в памяти. Не требует базы данных, подходит для показа работы сервиса в Bot-Control без настройки бэкенда.

### Импорт в Bot-Control

Для приложения Bot-Control берите файл **`bot/imitation_bot.txt`** — это тот же код,
но с расширением `.txt` для вставки через «Скрипты → Импорт настроек из кода».

Конфиг рассчитан на статический анализатор BotControl, поэтому в нём:

| Требование импортёра | Как выполнено |
|---|---|
| Нет `import`, `parse_mode`, f-строк | Ни одного вхождения |
| Текст ответа не «вычисляется в коде» | Все 32 текста — строковые литералы |
| У каждого `callback_data` есть обработчик | 18 кнопок → 18 функций с точным сравнением |
| Inline-меню не висят без привязки | 5 меню без аргументов, все прикреплены |
| У каждой reply-кнопки есть правило | 11 кнопок → 11 правил `m.text == "..."` |
| Лимиты Telegram | Тосты ≤180, тексты ≤4096, меню ≤12 кнопок / ≤8 рядов |

Подробный разбор всех замечаний импортёра, карта кнопок и сценарий проверки —
в **[`BOT-CONTROL-IMPORT.md`](BOT-CONTROL-IMPORT.md)**.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PODRABOTKA_BOT_TOKEN` | *(обязательно)* | Токен бота от @BotFather |
| `PODRABOTKA_DB_PATH` | `data/podrabotka.sqlite` | Путь к общей SQLite-базе веб-версии |
| `PODRABOTKA_DATA_DIR` | — | Альтернативная папка с `podrabotka.sqlite` |
| `PODRABOTKA_WEB_URL` | `https://visiontripin.github.io/Podrabotka/app.html` | URL веб-версии (кнопки «🌐») |
| `PODRABOTKA_LANDING_URL` | `https://visiontripin.github.io/Podrabotka/` | URL демо-страницы |
| `PODRABOTKA_NOTIFY_INTERVAL` | `15` | Секунд между опросами новых уведомлений |
| `PODRABOTKA_JOBS_PAGE_SIZE` | `5` | Смен на одной странице каталога |
| `PODRABOTKA_CHAT_HISTORY` | `8` | Сообщений в мини-чате |

База должна существовать — запустите веб-версию один раз (`npm run dev`), она
создаст и наполнит `data/podrabotka.sqlite`. Для тестов бота используйте
копию через `PODRABOTKA_DB_PATH`, никогда не меняйте сидинг-базу напрямую.

## Модель синхронизации через общую SQLite

Бот и веб-сервер открывают один и тот же файл `.sqlite`:

- **Веб (Node, `node:sqlite`)** — основной интерфейс, пишет задания, отклики,
  уведомления (`notifications`).
- **Бот (Python, `sqlite3`)** — читает те же таблицы и пишет только в
  bot-собственные таблицы:
  - `bot_telegram_links(telegram_id PK, user_id UNIQUE, notify)` — привязка
    Telegram-аккаунта к аккаунту на сайте.
  - `bot_meta(key, value)` — служебные данные бота, в т.ч.
    `notification_cursor` — курсор последнего разосланного уведомления.

**Нотификатор** (фоновый поток, интервал `PODRABOTKA_NOTIFY_INTERVAL`, по
умолчанию 15 с):
1. Берёт `notification_cursor` из `bot_meta`.
2. Вызывает `db.poll_unsent_notifications(cursor)` — новые строки
   `notifications.id > cursor` для пользователей с `bot_telegram_links.notify = 1`.
3. Шлёт каждое уведомление в Telegram (`telegram_id`) с подсказкой раздела
   (`target_tab` → кабинет/каталог/профиль/модерация).
4. Сдвигает курсор в `bot_meta`.

WAL-режим + `busy_timeout` + короткие транзакции `BEGIN IMMEDIATE` позволяют
вебу и боту работать с базой одновременно без конфликтов блокировок.

## Связь с Bot-Control

Ваше приложение **[Bot-Control](https://github.com/visiontripin/Bot-Control)**
испортирует конфиг бота по модели `*-ready.py`:

- Бот-Control **парсит** готовый конфиг, он не исполняется как произвольный код
  напрямую приложением, но отдельный запуск `python bot/podrabotka_bot.py`
  работает автономно.
- Токен бота не хранится в репозитории — он задаётся через переменную
  `PODRABOTKA_BOT_TOKEN` (в Bot-Control токен задаётся в настройках импорта).
- Общая база SQLite — единый источник истины: действия пользователя в боте
  (отклик, принятие смены, отзыв, чат) мгновенно видны в веб-версии и
  наоборот.

## Роли и возможности

**👷 Исполнитель:** каталог со фильтрами (категория / район / дата), быстрые
выборки «Сегодня/Завтра», избранное, отклик с запиской, мои отклики (отмена,
чат, оценка смены), профиль и тарифы, уведомления в Telegram.

**🏢 Работодатель:** мои смены (активна / пауза / закрыта), создание смены за
парой шагов, клонирование, кандидаты (принять / отклонить / завершить смену и
выплатить), мини-чат с исполнителями.

**🛡 Модератор:** обзор платформы (активные смены, средняя оплата,
верифицированные работодатели, отклики и отзывы в ожидании), одобрение/отклонение
отзывов.

## Тестирование

Все модули проходят `py_compile`. Функциональная проверка проводилась против
временной копии базы (`PODRABOTKA_DB_PATH`, `tempfile`) с заглушкой
`telebot.TeleBot`: привязка аккаунта, каталог, отклик, избранное, создание
смены работодателем, принятие/отказ/закрытие, модерация отзывов, доставка
нотификаций и сдвиг курсора — пройдены.
